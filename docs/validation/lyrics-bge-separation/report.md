# BGE 中文歌词检索：分别、离别

2026-10-20。独立实验，未修改 Current App。

## 配置

- 主题：分别、离别。仅编码该主题及 BGE 官方检索指令，没有人工扩写主题。
- 网易云 API 返回 12 首原词/译词；清洗后 8 首有可检索中文文本，共 164 个窗口。
- 中文原词或网易云中文译词，4 行一块、步长 2 行；去除人员名单与重复窗口。
- 社区 INT8 ONNX，512 维，CLS pooling + L2；每首按最高相关窗口排序。
- 歌名、歌手、音频及此前人工风格评分未加入向量输入。
- 结果是候选排序，不是情绪分类或置信概率。中文模型未测试外文原词检索效果。

## 覆盖边界

- After Party：没有足够中文歌词，不用中文模型硬匹配。
- Coolest Dog On The Street：未取得可用歌词。
- 请柬、我是你的老鼠：清理演奏人员等信息后，没有足够中文正文；不据此推断纯音乐。
- 后几名可能只是弱相关候选。需要用户核对，不能按排名宣布准确率。
- 原始歌词只作为本地实验输入保存在 .runtime，不作为报告内容发布。

## 复现

模型版本、权重哈希、分词器哈希、pooling、切块、语言筛选见 manifest.json。索引构建约 0.99 秒，是 Mac 单线程实验结果，不能代替 iPhone 12 性能测试。
