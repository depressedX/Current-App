## 手动验收：无账号也可先看交互

1. 打开 Current.xcodeproj，选择 Current scheme、自己的 iPhone 或已有模拟器。
2. 点击「先体验一下」，输入一句话，点击「生成歌单」。
3. 看到成功提示、8 首随机演示队列和底部迷你播放器。音频为本项目原创合成片段。
4. 打开完整播放页，检查播放/暂停、上一首、下一首、进度拖动。
5. 点击爱心；打开「不合适」，选择原因。原因反馈会记录并跳到下一首。
6. 到「我的」查看反馈和最近队列，重播历史。
7. 杀掉 App 再打开、进入演示空间，确认记录还在。
8. 退出演示空间，确认音频停止且当前队列清空。

## 手动验收：真实网易云

1. 点击「连接网易云」，使用网易云 App 扫码确认。同机可截图二维码后从网易云相册识别。
2. 返回 Current，确认头像、昵称、用户 ID 正确。
3. 在音乐库选择用户歌单。此期只读前 100 个歌单、每个歌单前 60 首。
4. 输入文本，生成随机队列；抽查真实歌曲、进度、错误提示。
5. 重启 App，验证登录恢复。断网恢复失败时不应擅自删除凭据。
6. 退出登录，确认播放停止。重启后不应恢复到刚才账号。
7. 如存在仅试听/无权限歌曲，应显示原因，不能假装成功或替换音源。

## 手动验收：CarPlay

1. 使用 CurrentCarPlay scheme；配置获批的 Team/profile。普通 Current 不声明 CarPlay。
2. iPhone 先完成登录与生成队列，再连接车机。
3. 检查「此刻队列」「最近的此刻」、系统正在播放、下一首、爱心反馈。
4. iPhone 切歌和登出时，车机队列同步更新。
5. 驾驶端不提供自由文本输入或账号扫码操作。
