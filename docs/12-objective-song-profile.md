# 客观歌曲分析 v1

> 当前产品范围：仅展示乐器识别；人声、听感平稳程度为待定。风格已通过独立 Discogs-EffNet 链路接入，见 [风格接入](15-genre-analysis.md)。下文其余维度保留为实验记录，不作为产品判断。

先回答可验证的问题；暂不把阴郁、浪漫等相似度当成歌曲属性。

## 当前输出

| 属性 | 方法 | 边界 |
|---|---|---|
| 人声出现情况 | Apple SoundAnalysis，整首歌按 3 秒窗口分类；speech / singing / choir / rapping 取最大分数 | ≥0.65 记明确，0.2–0.65 记不确定。不确定窗口超过 25% 时总判定也为不确定。是片段计数，不是人声能量占比 |
| 人声突出程度 | 暂不判断 | 需要专门模型或分离声部，不能从出现次数推导 |
| 响度起伏 | 每秒多声道平均功率；有效秒 RMS dBFS 的 P90−P10 | 低于 −60 dBFS 不参与跨度；不是 LUFS 或标准 LRA |
| 持续响度突增 | 前后各 3 秒平均电平差 ≥6 dB；相邻事件合并取最大值 | 标出秒数；忽略静音起播，不能把每次鼓点当高潮 |
| 频谱变化 | 左声道 1024 点 Hann FFT，7 个宽频带归一化；约 3 秒聚合，邻段总变差距离的最大值与 P90 | 0–1 原始指标；不受整体音量直接缩放影响。不是风格或情绪判断，立体声空间变化未覆盖 |
| 明确声源 | 系统分类器高分声源出现至少 2 个窗口，多标签 | 未检测到不等于不存在；不能据此直接断言 rock / house |
| BPM、周期强度 | 保留网易云百科优先、本地中段 45 秒估计回退 | 半速/倍速歧义保留；周期强度不是节拍置信度 |

响度较平稳：跨度 ≤5 dB 且最大持续突增 <6 dB；起伏明显：跨度 ≥10 dB 或突增 ≥9 dB。其余为有一定变化。覆盖不足不做全曲结论。

## 工程链路

1. 保留现有下载、格式识别、BPM 查询。
2. utility 工作任务串行读全曲，8192 帧缓冲；逐秒功率与频谱统计，SoundAnalysis 同步送入同一批 PCM。
3. 等待分类完成；保留“无法判断”，不将失败当作无人声。
4. 新增可选 `AcousticFeatures.profile`，版本 `objective-v1`；现有歌曲池原子存储直接保存摘要，无 PCM、逐帧向量或音频副本。
5. 详情页优先展示客观维度；DCLAP 仍保留为实验性概念相似度。

无新增模型下载或第三方依赖。沿用播放抢占、后台暂停和取消检查；单个文件上限 2 小时，突增时间点最多展示 32 个。旧存档可读，点击“重新分析”或“更新歌曲分析”升级。

## 歌单验收

- 选择纯音乐、持续人声、长前奏后进人声、稳定氛围音乐、有明显段落突增的歌曲。
- 先记录人工判断，再看检测结果，避免按模型结果倒推答案。
- 重点核对：人声窗口、不确定窗口、突增时间、响度跨度、频谱变化、声源漏检。
- 系统声音分类器并非专用音乐模型；阈值仍需歌单标注校准。若混合音乐中人声漏检明显，应换专用 vocal/instrumental 模型，不靠调低阈值掩盖。
- Mac 回归/构建只能证明链路可用；iPhone 12 的耗时、峰值内存和温升仍需真机测量。

## 下一步

优先补专用人声检测与节拍稳定性；大风格分类需要标注歌单对照后再决定模型。不从当前声源分类硬推风格。推荐系统消费属性时，需同时读取来源、版本、覆盖率和未知状态。
