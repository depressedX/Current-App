# Current 视觉规范

参考：Kumone 的 DesignSystem/Theme.swift、ButtonStyles.swift，以及用户提供的界面截图。
本项目独立实现样式；保留原生 iPhone 导航，不搬入 macOS 侧栏。

## 色彩

- 强调：暖红 #EC4949，主要按钮使用至 #C92929 的轻渐变。
- 背景和表面：系统 background / secondarySystemBackground，随浅深色变化。
- 正文 primary，辅助信息 secondary。封面可以有颜色，其余不堆叠彩色容器。

## 字体

全部系统字体，随 Dynamic Type 缩放。仅标题和重点信息加重。

| Token | 默认字号 | 字重 | 用途 |
|---|---|---|---|
| title | 28 | bold | 页面主标题 |
| section | 20 | semibold | 分组、歌曲标题 |
| body | 15 | regular | 正文、输入、操作 |
| emphasis | 15 | semibold | 歌曲行主文本 |
| secondary | 13 | regular | 描述、次要操作 |
| caption | 12 | regular | 时长、状态 |

多行说明增加 4pt 行间距，标题保留系统行高。不使用衬线字或字距装饰。

## 布局

间距：4 / 8 / 12 / 16 / 24 / 32pt。页边距 24pt。
圆角：6 / 8 / 12 / 20pt；胶囊形仅用于主按钮与短暂提示。
内容最大宽度 640pt，播放器 480pt；在 Mac 直接运行时不把输入框和段落拉满窗口。
歌曲行封面 48pt，交互命中范围至少 44pt。列表用少量高亮表达选中，不给每行套卡片。

## 图标

统一 SF Symbols，与 Kumone 的系统图标语言一致，不新增图标依赖。
仅用于导航、播放控制、选中、收藏和进入下一级。
不在标题、输入提示、推荐短语、反馈原因旁加装饰图标；封面占位不重复波形图标。
图标尺寸独立为 Icon token，不能影响文字字号。

## 动效

按压：0.15s easeOut，轻微缩放至 0.98、透明度变化。
列表：0.15s 行高亮；选中状态用背景/文字表达。
迷你播放器：0.25s 出现/消失；弹层使用系统转场。
开启 Reduce Motion 时取消缩放、位移和自定义动画。
不做循环发光、装饰跳动或重复入场动画。

## 文案

首页只保留需求输入、示例和一句随机选歌说明。
算法、反馈存储和演示音频细节放在「我的 → 关于 Current」。
登录同机操作说明按需展开。

## 推荐反馈

播放器将「不合适 / 喜欢」作为并列主要操作，60pt 高；暖橙/暖红实色渐变，图标与文字同时显示。
喜欢后显示「已喜欢」和选中描边，同一已喜欢状态不重复记录；不合适继续打开原因面板。
普通播放按钮改为中性色，避免与推荐反馈争夺强调色。封面高度随可用高度收敛，优先露出反馈操作。
爱心永不映射为网易云收藏。当前只保留推荐信号，不宣称尚未实现的权重更新已生效。


### 播放反馈

- 播放控制下方并排「不合适」「喜欢」，44pt 点击区域，默认无色底；选中喜欢后使用主题红。
- 不合适：记录「不适合此刻」并切歌；底部提示保留 8 秒，可撤销这次反馈或修改范围。
- 范围：不适合此刻 / 暂时不想听 / 不喜欢这首。修改同一条记录，不重复切歌。
- 撤销只删除反馈，不打断当前播放。三个范围先保存为信号，实际降权与暂时屏蔽待推荐算法接入。
- 所有偏好只属于 Current，永不同步网易云收藏。
