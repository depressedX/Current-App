# Mac 分析伴侣

## 启动与验收

1. Xcode 打开 `Current.xcodeproj`，选择 `CurrentCompanion`，目标选 **My Mac**，运行。
2. iPhone 运行 `Current`，两端保持在附近、开启 Wi-Fi，并允许本地网络访问。普通局域网与 Apple 点对点 Wi-Fi 都可作为连接路径。
3. 手机进入 **我的 → 歌曲池 → 交给 Mac 分析**，找到对应 Mac，点击 **请求配对**。
4. Mac 弹出请求，点击 **接受配对**，才会生成并显示 **4 位数字**；手机随后进入输码页，点击 **验证并连接**。拒绝、取消、等待超过 60 秒或配对码超过 5 分钟会结束请求；输错可重试，最多 5 次。
5. 配对成功后自动记住设备，后续自动连接；重新配对需要再次请求并确认。
6. 首次配对会复用手机网易云授权；授权过期后，在手机点击 **更新网易云授权**。
7. 选少量歌曲，点击 **交给 Mac 分析**。每完成一首自动同步，歌曲池中可查看结果并用于推荐、歌词检索。

建议先用 2–3 首歌验证：

- 手机退到后台，Mac 继续分析；手机回来后自动补传。
- 分别暂停分析、暂停同步，确认互不影响；同步失败可恢复重试。
- 关闭 Mac 主窗口后，取消当前分析、关闭连接并退出；重新打开后手动继续未完成任务。
- 单首失败后继续其他任务，手动重试失败项。
- 手机移除歌曲后，联网通知 Mac 取消，不导入迟到结果。
- 手机退出账号后，联网通知 Mac 清除授权、取消旧任务。
- 选择“本机分析”属于明确切换，不会因 Mac 离线自动开始。

## 已实现

- 原生 SwiftUI 单窗口、侧栏、任务状态，配对弹层依附主窗口；沿用 Current 红色强调色和 Kumone 的原生布局习惯。
- Bonjour 发现、4 位数字 SRP-6a 配对、TLS-PSK 加密连接；短码只用于首次验证，独立随机长期密钥与网易云凭据仅进 Keychain，后续自动重连。
- Mac 并行度可在任务页选择 1–16 首，默认 4 首，重启后保留。调高立即补入，调低等当前任务自然完成后再按新上限补入；每首内部保持串行、模型单线程。暂停和关闭窗口会取消全部运行任务，单首取消不影响其他歌曲。
- 手机只发送歌曲元数据与授权；Mac 自行请求音频、百科和歌词，复用原生分析器。
- 单首完成即同步。手机写入向量及目录成功后确认；重连补传未确认结果。
- 本地持久任务与结果分开保存，避免阶段更新反复写入整库向量。
- 每次提交有独立标识，旧结果和旧确认不会覆盖新的重新分析。
- 账号、歌曲记录、模型版本校验；失败结果不覆盖旧结果；分析结束删除临时音频。

## 日常操作

- 手机只显示待处理任务与待选歌曲，已提交歌曲不再重复出现在选择列表；任务明细默认收起，先展示总进度。
- “全选 / 取消全选”共用一个入口；暂停、失败重试只在有对应任务时出现。
- 重新分析、主动更新授权、暂停同步、解除配对放在右上角“更多”。授权失效或同步暂停时，页面单独显示恢复入口。
- 手机保存结果后确认，Mac 先持久化移除任务，再删除结果副本；手机歌曲池中的分析结果保留。未确认的结果仍保留并支持重连补传。
- 旧版本积累的“已同步”任务会在启动时自动清理。

## 点对点连接

- 搜索、配对和加密连接均启用 Apple 点对点 Wi-Fi，不需要固定 IP 或同一公司子网。
- 用户选中设备后停止搜索，连接使用本次发现的接口作用域，保留 AWDL 链路本地路由；断线后重新发现，不复用已经失效的 USB 记录。
- 单次搜索最多 30 秒；已配对设备离线后按 5、10、20、40、60 秒的间隔重新搜索，连接成功后重置间隔。
- Mac 未连接手机时也进行限时点对点搜索，避免只发布而未唤起附近发现；连接成功或关闭窗口后停止。
- 手机后台停止搜索和连接，回到前台重新发现并补同步。Mac 关闭窗口后撤销全部监听、重试和分析任务。
- 无线直连的距离、公司设备管理限制和实际稳定性仍需 iPhone 与 Mac 现场验收；命令行检查不代替点对点无线验证。

## 配对排障

若手机能看到 Mac，但请求后没有弹窗：

- Mac 的发现和配对使用同一个 `_current-an._tcp` 类型，配对使用独立实例，避免新增类型被系统旧注册信息拒绝。
- 配对监听失败会显示错误与重试入口；应用日志的 `companion` 分类记录发现、连接、请求、确认和弹窗阶段。
- 日志不保存设备名称、配对码、长期密钥或网易云凭据。

发现列表按稳定设备标识去重，配对入口和缺少有效设备声明的旧广播不作为电脑展示。同名但不同标识的 Mac 会分别保留。测试监听仅绑定回环地址，使用独立 `_current-test._tcp` 类型，结束时主动撤销发布。

## 自动检查

```sh
zsh Scripts/check-companion.sh
zsh Scripts/check-analysis.sh
zsh Scripts/check-playback-queue.sh
```

`check-companion.sh` 使用测试授权与内存凭据存储，不读取或修改真实网易云凭据；覆盖真实 TCP 配对和 TLS 重连、显式接受/拒绝、取消与超时、前导零、错误配对码、重放和篡改拒绝、服务端批量任务、同步暂停/重连、确认、结果持久化、账号撤销，以及导入结果用于推荐排序。

尚需真机验收：拔掉 USB、两端处于不同公司子网时的点对点发现与连接，实际网易云登录态在 Mac 的可用性，以及完整模型分析后的手机展示。命令行测试中的授权接口和分析输出使用固定测试数据，不代替这些验收。

离线退出账号无法立即通知 Mac。需要立即撤销时，在 Mac 点击 **解除配对并清除授权**。
